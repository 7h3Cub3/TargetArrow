# TargetArrow v1.0.0

**TargetArrow** is an Ashita 4 addon built and tested for **HorizonXI**. It adds a configurable in-world target indicator while HideParty hides the native party and target interface.

## Features

- Classic gold target and green subtarget cursors.
- Configurable scale, vertical positioning, individual color presets and custom RGB colors.
- ImGui configuration window using `/ta config`, including **Restore Defaults**.
- Optional vertical bobbing and opacity flashing; **both disabled by default**.
- Automatic visibility guard that suppresses the replacement cursor when HideParty is not actively hiding the relevant native frames.
- Target model-based positioning that is independent of visible nameplates.
- Diagnostic information using `/ta status`.

## Installation

Download **TargetArrow-v1.0.0.zip** below and extract it into `HorizonXI\Game\addons\`. Enable HideParty and configure the HorizonXI startup script to load TargetArrow.

Read the [installation instructions](https://github.com/7h3Cub3/TargetArrow#installation-and-launcher-activation) for the full setup.
